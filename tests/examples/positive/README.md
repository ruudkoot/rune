# Positive examples

Programs accepted by the Rune expression compiler belong here. Every
`*.sml` file has a same-named partner in `../negative/`; the partner adds one
invalid lexical character. The corpus is run by
`tests/examples/run_lexer_examples.sh` against native SML/NJ, Poly/ML, and
MLton, and against RuneCompiler hosted by each of those toolchains.
