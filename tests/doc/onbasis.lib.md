### <a name="val-count"></a>`count`

```sml
val count : string -> int
```

`count s` is the number of words of `s`, the tokens of [`String.tokens`](../../basis/sig/STRING.md#val-tokens)
that [`Char.isSpace`](../../basis/sig/CHAR.md#val-isspace) separates.

**Raises** [`Size`](../../basis/sig/GENERAL.md#exn-size) never; the name is the Basis Library's.

**Example** `count "a b  c" = 3`
