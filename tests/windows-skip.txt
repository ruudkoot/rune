# Programs of tests/lang that `make test-windows` leaves out, one per line:
#
#   NAME CATEGORY: reason
#
# Categories:
#   SOCKETS   the system layer of Windows has no sockets: they are Winsock,
#             which needs WSAStartup and a separate set of calls, and
#             vm/sys_win.c answers ENOSYS
#   POSIX     fork, exec, wait, signals, pipes between processes, the file
#             modes and owners of POSIX, and the terminal settings: Windows
#             has none of them in this shape
#   POLL      sys_poll waits on descriptors, which on Windows is select over
#             sockets only and WaitForMultipleObjects over everything else
#   CRT       the C runtime of Windows differs from POSIX's in a way that
#             shows in what the program prints
#
# Everything else runs: 127 of the 136 programs pass on the Windows VM.
basis.inet6sock SOCKETS: INet6Sock.fromString asks the system to read an address
basis.inetsock_addresses SOCKETS: INetSock.toAddr builds a sockaddr
basis.netdb_lookup SOCKETS: the protocol, service and host databases are Winsock's
basis.socket_loopback SOCKETS: a TCP and a UDP socket on the loopback interface
basis.os.io_poll POLL: OS.IO.poll waits on descriptors
basis.posix_files POSIX: the modes, owners and links of a file
basis.posix_process POSIX: fork, exec and waitpid
basis.unix_pipes POSIX: a pipe to a child process
basis.date_year_of_c CRT: strftime of Microsoft's C runtime gives nothing for a year before 1970, where POSIX formats it
