# M2 binding model acceptance — 2026-10-23

The implementation follows M1 in the isolated `runeffi` worktree. The
`ffi/model` library separates foreign declarations, target facts, projection
policy and implementation coverage. It retains source identities, aliases,
compiler attributes and macro definitions without assigning native addresses
or silently inferring pointer ownership.

`bin/rune-ffi-model` is a development inspector, implemented in SML. Its
`inventory` command preprocesses original headers, resolves selected
functions/helpers/types and folds the selected integer constants. Its
`policy` command validates a version-one `.ffi` sidecar against the original
declarations. Inspection records selection or outstanding lowering work;
it never marks an entry generated merely because its name resolves.

## Focused evidence

* Pure policy suite: **48** positive/negative checks, including source
  diagnostics, explicit termination/lengths, ownership/nullability,
  deallocator/error-getter contracts, callbacks, unsupported selected types,
  raw variadics, output grouping, conflicting declarations and deterministic
  traversal. This is `tests/lib/ffi/model/policy.sml`.
* Linux SDL: **53** functions, **15** constants and **4** required types
  resolve uniquely. Both Windows SDL profiles resolve the same inventory.
* Windows SDK, both widths: **38** functions, **53** constants, **8** helper
  macros and **7** required types resolve uniquely. The helpers retain
  their own macro namespace and require typed shim lowering in M4.
* Original-header policy examples validate **24** fixture functions,
  **6** SDL functions and **5** Win32 functions. The SDL sample covers
  owned/borrowed strings, resources and returned width/height values. The
  Win32 sample covers UTF-16, clock outputs and the window-procedure failure
  table. These examples are not completed SDL/Win32 implementations.
* Native MLton, three SML/NJ hosts and Poly/ML pass the pure model suite.
  MLKit 4.7.25's default region inference reproduces the repository's
  documented JSON corruption bug; the unchanged **48** checks pass with
  `-no_ri` under the same 2 GiB address-space bound. The default failure is
  recorded as `HOST-BUG`, with a separate successful comparison job.
* Projected signatures, full M0 SDL/Win32 signatures and abstract-handle
  sharing witnesses pass on Rune and all six native SML hosts. Host checks
  load the relevant Rune Basis subset and retain native Int32 on default
  integer representations of at most 32 bits, as the host matrix does.
  These are type-elaboration witnesses, not native-call implementations.
* The host checks exposed default-Int assumptions in the construction of
  `2^32` in the generated host copies of Int64/Word64. The host adapter
  rewrites that construction only in signature-test copies to an explicit
  IntInf shift; Rune retains
  its original startup allocation behavior.
* Library/documentation checks before the final acceptance pass recorded
  **75/75** library cases and **11/11** documentation cases. The final full
  repository/host-matrix checks are recorded below when they finish.

## Reproduction

```sh
make test-ffi-model
RUNEFFI_WINDOWS_SDK="/path/to/10.0.22621.0" \
RUNEFFI_MSVC_INCLUDE="/path/to/MSVC/14.40.33807/include" \
  make test-ffi-model-windows
make test-ffi-model-hosts
bin/rune-test run 'lib-hosts/*/ffi.model.policy' 'runner/host-adapter' -j 6
```

The combined runner filter uses `tag:test-ffi-model | tag:test-ffi-model-windows
| tag:test-ffi-model-hosts`. Repeating `--tier` does not combine tiers.
Private output directories, bounded children and the shared MLKit build pool
are supplied by the existing SML test runner.

The [sidecar specification](../../../docs/ffi/sidecars.md) defines the schema,
fixed SML type vocabulary, resource names, grouping, callbacks and errors.
Target layout, typed declaration expressions, executable generation and
runtime callback support remain the later milestones' responsibilities.

## Repository acceptance

`make check JOBS=8` completed 19,387 cases: 19,382 passed, three documented
skips and two allocation-budget failures. Both failures were the single
extra startup object introduced by changing Rune's `2^32` construction.
The production construction was restored, and narrow-host adaptation moved
to the signature witnesses' private generated Basis copies. The full budget/generator
selection then passed **40/40**, and the final host-signature comparison
passed **13/13**. The original full command returned failure; these are
explicit successful repair runs, not a claim that it originally passed.

Final generated-document validation passed. The repaired
`make matrix-quick JOBS=8` completed **3,338/3,338** cases: **3,182 passed**,
**156 documented skips**, **zero failures**, in 2,920.0 seconds. Its evidence
is in `tests/out/r/20261023-031636-797571`. M2 is complete as of 2026-10-23.

The initial host-matrix run completed with 15 failures because the global
host-adapter rewrite changed which narrow-host Basis implementations could
load. That rewrite was removed from the shared adapter and confined to the
signature witnesses' private copies. The local signature/no-region-inference
selection passed 13/13 after isolation. The repaired full host matrix passed as recorded above; the initial failed
result is not counted as success.
