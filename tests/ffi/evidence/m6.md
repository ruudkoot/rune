The subsequent generic public component adds `ForeignPublic`, generated
ownership and borrow guards, UTF-8/UTF-16 text, element-counted byte arrays,
scalar out/inout parameters, immediate native error capture and same-thread
call-scoped callbacks. `ForeignGenerated.createChecked` verifies measured C
scalar widths/alignments and architecture before opening any library; this
rejects the Linux LP64/Windows LLP64 mismatch at equal pointer widths.

The public fixture is generated entirely from `safe.h` and `safe.ffi`. Its
SML client has no handwritten foreign call bridge. The native subject tests

The restricted sanitizer toolchain probe failed because LeakSanitizer
cannot operate under ptrace. The exact build/check outside the sandbox
passed with leak detection enabled. An initial explicit UTF-16 extent
fixture exposed missing parentheses around generated `SOME` arguments;
the emitter was corrected and the full current-source execution gate above
passed. No failing source run is relabeled as a passing run.

The aggregate follow-up emits typed call shims for by-value struct arguments
and results, original static/inline definitions and nonstandard calling
conventions. Public nested structs become complete records and fixed native
array fields become checked vectors. The same codec supports scalar/struct
out and inout pointers. Raw aggregate shims insert an output pointer before
normal arguments, returning void. The manifest records the exported symbol
and `typed-c-shim` mechanism, and coverage reports `shimmed` separately from
ordinary dynamic calls. Array-valued field getters reject with a diagnostic
rather than emitting an invalid C function returning an array.

Validation of this follow-up: 35 contracts across five execution modes
(175 PASS), the shared policy suite (48 checks), pure generator (14), full
SML/NJ elaboration and exact Poly/ML inspection agreement all passed. Both
sanitizer VMs then passed all 35 contracts (70 PASS), with the C subject and
emitted shim also compiled with `-fsanitize=address,undefined`. The native
run additionally exercised 128 repeated owned/borrowed retirement cycles;
the permanent fixture uses 16 bounded cycles. An earlier sanitizer run was
stopped deliberately to remove redundant cycles and add native-shim
instrumentation; that stopped run is not an acceptance pass. Documentation

claim and note consistency checks passed using the explicit compiler/helper
paths. M6 is still planned.

The registered-callback component transfers rooted closures and retained
resource-parameter leases to an owned returned resource. Its annotated
single-pointer void destructor is the explicit unregister protocol and must
stop all callbacks before returning. The ordinary generated resource API
therefore controls both native ownership and callback lifetime. Null results
release pending roots; registration exceptions dispose any newly returned
owner first. The provider can issue a last callback while unregistering;
callback exceptions escape after native disposal and root cleanup.

The generic C fixture now tests 43 contracts: five native modes pass 215
checks and both sanitizer modes pass 86, with the C provider and emitted
shims instrumented. Added checks cover delayed callback dispatch, retained
context close guards, exception recovery with a live registration, the final
destructor callback, failed/nullable registration cleanup and exceptions
during unregister. Native allocation counts and the complete registry return
to zero. Complete SML/NJ generator elaboration and exact Poly/ML inspection
agreement pass; generated model documentation is current. Registration
protocols without an owned returned handle remain explicit adapters.

Selected macro/fixed variadic integration adds `ForeignAdapter` and the
optional `shim` field containing one fixed C prototype. The pure SML parser
rejects extra declarations, bodies, storage classes, aggregate definitions,

emission. Original macro namespace/source and the explicit prototype remain
in provenance. Native C performs integer and floating default promotions for
the fixed variadic tail. Headers remain unchanged and the generator executes
no compiler or command.

This component passes 47 contracts in five execution modes (235 PASS) and
