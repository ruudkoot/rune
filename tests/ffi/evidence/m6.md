# M6 generator implementation evidence

State: **planned**. This record covers the first implemented generator and
publication component, not the complete M6 gate. Date: 2026-10-23.

Baseline: generator worktree from `831b45182`, shared target/C analysis
integration `689d5718c` (equivalent to `a11bf086d`). Source generation,
filesystem driver and runtime session helpers are SML. C is emitted only
for typed foreign field adapters and used independently as a call oracle.

Delivered:

- `runeffi.build`, self-hosted CLI, MLton/Poly/ML build integration and
  installation wrappers;
- deterministic fixed native descriptors, raw sessions, scalar public
  projections, target measurements, typed field getters/setters and
  declaration/dependency provenance;
- immutable generations and atomically replaced `current.build`, separate
  stable public signature identities and existing `.build` virtual modules;
- strict `check`, explicit header roots/options, target integer constant
  evaluation without artificial int-enum truncation;
- focused C/native/generated client, publication and host comparisons.

Actual focused validation used the existing compiler and VM in the separate
`runeffi-layout` worktree while this worktree's sources were the inputs:

Native C subject: `cc -std=c17 -Wall -Wextra -Werror -shared -fPIC`, GCC
13.3.0 on Linux x86-64. The generator also emitted all 53 selected SDL3
functions from the unchanged pinned headers, selected event/surface/rect
layouts, enum constants, and pointer-valued surface/text field adapters.
That emission is evidence for generator handling, not SDL behavior acceptance.

Initial development checks found and repaired missing UTF-8 sources in the
standalone host build, a C `_Bool` value-bit width versus object-byte width
distinction, forward aggregate definitions in field accessors, incomplete
doc usage heads, and a missing fixture directory. An initial relative API
path included the immutable implementation revision in its source identity,
which recompiled the client on implementation switching. Publishing stable
API paths directly from `current.build` repaired that regression; the test
now asserts the client was taken from cache. A development VM invocation
used `--gc-stress=7`, which the VM rejects; the recorded passing invocation
uses its documented `--gc-stress 7` spelling.
