# M4 acceptance evidence (in progress)

Date: 2026-10-23. M4 remains planned until all marshalling and adapter gates
are met. This file records completed components without claiming the
whole milestone or later generated bindings.

## Target analysis

The target analysis implementation adds `CInteger`, `CType`, `CExpression`
and `CLayout` to the reusable SML C library. The declaration parser also
exposes abstract type-name parsing. Equivalent scalar spelling is now
shared with `ForeignModel` rather than duplicated.

* `tests/lib/language/c/target.sml`: **83 checks**, including LP64, LLP64,
  both 32-bit alignment models, casts, promotions, lazy evaluation,
  unevaluated `sizeof`, arrays, unions, packing and explicit rejection.
* The unchanged frontend and new target suites passed on MLton, SML/NJ
  110.99.9 64/32-bit, SML/NJ 2026.2, Poly/ML and MLKit: **12 host suites**.
* Native probes compared **23** results on each of Linux x86-64/x86,
  Windows x86/x64, AArch64 and big-endian PowerPC: **138 comparisons**.
  Cross targets use the repository's Clang/sysroot/QEMU configuration;
  Windows probes use the installed MinGW toolchains and native execution.
* The final library selection passed **12/12** runner jobs, including the
  runner's canaries. The host/oracle/documentation selection passed 31/32;
  its sole failure was the host-inventory test's old hard-coded count after
  adding a suite. The count and an explicit target-suite coverage assertion
  were repaired; the focused repair selection then passed **6/6**. The
  final stack-interpreted target suite also passed **83/83**.
* `make docs JOBS=4` passed. Generated documentation is committed.

Reproduction:

```sh
make test-c-layout
bin/rune-test run 'lib/language/c/*' 'lib/ffi/model/*' -j 4
bin/rune-test run 'lib-hosts/*/language.c.target' \
  'lib-hosts/*/language.c.frontend' 'ffi/layout/*' \
  'ffi/frontend/fixture' 'runner/host-adapter' 'documentation/*' -j 6
```

Initial native-oracle compilation exposed a percent sign in a stringified
expression being treated as a printf directive. The oracle now prints the
expression through a `%s` argument. No failed initial run is counted as a
successful comparison. A first runner selection incorrectly combined
explicit filters with a tier intersection; its five canaries alone were
not acceptance evidence. The actual named selections are recorded above.

The [layout contract](../../../docs/ffi/layout.md) records supported
constructs and explicit adapter boundaries. Complete native marshalling,
selected SDL/Win32 layouts, compiled shims and repository/host acceptance
remain outstanding for M4.

## Portable cleanup and byte/text representations

`ForeignScope`, `ForeignBytes` and `ForeignText` are ordinary SML helpers
under `lib/ffi/marshal`. The core suite passes **67/67** on Rune, including
128-bit integer limits, both byte orders, independent binary64 bytes,
strict UTF-8, WTF-8, preserved lone UTF-16 surrogates, terminator bounds and
cleanup ordering/exception priorities. Native MLton and Poly/ML pass all
67 checks. Native SML/NJ's optional default-real packing structures are
absent; native MLKit reproduces its documented large-shift bug in six
endpoint cases. These are explicit `HOST-ABSENT`/`HOST-BUG` records, not
claims of passing the missing or broken operations. The native-host runner
selection passes **12/12** including canaries with those deviations.

The initial sized-real packing choice exposed SML/NJ's existing swapped
`PackReal64` byte order and Poly/ML's absent aliases. The helper now uses
the default-real packing interface corresponding to its SML `real` type,
checks that interface's byte width and records native SML/NJ availability.
No compiler-specific packing or integer-shift workaround is present.

## Native buffers and generated adapters

`ForeignMemory` adds explicit retained buffers, bounded native-pointer
views and scoped SML array copies. Its **23** checks pass in stack and
register interpretation, both JIT tiers and native `runeopt` execution,
with collection stress and heap verification. Overlapping arguments share
one allocation. Output copying and cleanup also run after body exceptions.
The runtime/documentation regression selection passes **23/23**, including
sanitizer preparation and both sanitizer VMs.

`CDeclarator` and `ForeignShim` generate target C adapters without executing
commands. **23** parser/declarator/adapter tests pass on Rune and all six
native SML hosts. A second suite compares the complete generated C bytes
on every host with Rune, then compiles that source against independent
prototype declarations in `tests/ffi/shim.h`. Original `fixture.h` bytes
remain unchanged. Native C checks cover aggregate arguments/results,
unions, packed bitfields, pointer/function-pointer fields, inline
functions, macros and fixed variadic adapters with C default promotions.
The C oracle and SML/libffi round trips pass on Linux and native Windows
x86/x64; the SML round-trip program has **17** checks, including adjacent-byte preservation
for packed bitfields under each compiler's layout rules. Linux x86, AArch64
and big-endian PowerPC additionally pass the compiled C adapter oracle;
dynamic calls there remain a later provisioning/portability gate.

The final adapter/Windows/sanitizer/host-generation selection passes
**21/21**, zero skips or failures, in 83.2 seconds. The final expanded packed
fixture plus documentation selection then passed **27/27** in 40.3 seconds. Earlier host comparison
failures came from interpreting SML/NJ's remaining source-file arguments
as an output path, and stripping blank lines from comparisons. The fixture
now requires an explicit output flag and compares marked bytes. The first
Windows runtime cases were skipped because the capability-probe wrapper
had not been built; building `bin/rune-windows` enabled both and they passed.
These failures/skips remain recorded, not counted as initial successes.

```sh
make test-ffi-shims test-ffi-shims-hosts
make test-ffi-runtime test-ffi-runtime-asan test-ffi-runtime-windows
bin/rune-test run 'lib/ffi/runtime/*' 'lib/ffi/model/shim' \
  'lib-hosts/*/ffi.model.shim' 'runner/host-adapter' -j 6
```

The delivery checkout's preceding target-analysis snapshot passed full
`make check JOBS=8`: **19,450/19,450** cases, **19,447 passes**, three
existing documented skips, zero failures. Its host matrix remains running;
that result does not substitute for acceptance of later ownership changes.

## Selected-header analysis, ownership and floating-point completion

`CAnalysis` now indexes original declarations lazily and evaluates selected
aliases, enum values, object measurements and typed macro expressions.
`ForeignTarget` validates explicit ABI profiles, including enum policy,
size_t, scalar alignment and preprocessing facts. All 24 analysis checks
pass on Rune and all six native SML hosts. The corrected host selection
passed **20/20** jobs. Profile decoding has **19** positive/negative checks;
native MLKit reproduces its JSON region-inference fault, while unchanged
sources pass with `-no_ri`. Initial fixture failures (missing test-library
metadata and a polymorphic NONE subject to the value restriction) were
repaired. Restricted 32-bit host executions exited on a disallowed syscall;
the unrestricted rerun passed. The first dedicated no-region-inference
harness omitted the unit library's property/random dependencies; its
repaired comparison passed **6/6** jobs including canaries.

The SML header-layout consumer measures the four selected SDL types and
all seven Win32 types without editing upstream bytes. Independent C probes
compile the same SDL originals and the actual pinned Microsoft SDK headers
using Clang's Microsoft target ABI, then execute on native Windows. Each
SDL profile agrees on **60** sizes, alignments, member offsets and constants.
Each Windows profile agrees on **137** facts, including **24** boundary
expressions covering all eight selected macro helpers. The native Linux
SDL oracle also agrees. Windows probes link UCRT only for printing facts;
Clang supplies the original-header measurements. SDL probes define
SDL_MAIN_HANDLED to keep their own entrypoint; an initial compilation
without it exposed upstream's main redirection. A restricted execution
failed with WSL UtilBindVsockAnyPort socket failed 1; unrestricted execution
passed. Original headers were preserved throughout.

`ForeignOwner` provides shared owner identity, borrowed scopes, guarded
transactional destruction, failure/retry and scoped cleanup. Its **19**
checks pass under collection stress and heap verification. The expanded
runtime gate passes **10/10** runner jobs covering stack/register/JIT,
`runeopt`, ASan/UBSan and Windows x86/x64; this includes the existing memory,
scalar, disposal and lifecycle fixtures.

`ForeignBytes` supports IEEE binary32 through checked binary64 bit
conversion, rounding nearest with ties to even, explicit infinities and
canonical quiet NaNs. Its expanded portable suite passes **78/78** on Rune,
MLton and Poly/ML. Native SML/NJ's absent default-real packing structures
remain HOST-ABSENT. Native MLKit's known large-shift fault affects eleven
checks, including five binary32 cases; those are HOST-BUG, not passing
operations. A native C oracle checks **1,039** narrowing/widening cases on
each of Linux x86-64/x86, Windows x86/x64, AArch64 and big-endian PowerPC:
**6,234** independent comparisons.

The final combined header/native/host/profile/marshalling selection passed
**34/34** runner jobs, zero skips or failures, in 54.1 seconds, with the
explicit native-host deviations above. An initial run had four SDK
capability skips because its environment variables were unset, plus the
no-region-inference harness dependency failure; those receipts remain
recorded. A separate corrected Windows selection passed **9/9**.
