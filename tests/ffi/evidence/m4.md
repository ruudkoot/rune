# M4 acceptance evidence (in progress)

Date: 2026-10-23. M4 remains planned until all marshalling and adapter gates
are met. This file records completed components without claiming the
whole milestone or later generated bindings.

## Target analysis

The target analysis implementation adds `CInteger`, `CType`, `CExpression`
and `CLayout` to the reusable SML C library. The declaration parser also
exposes abstract type-name parsing. Equivalent scalar spelling is now
shared with `ForeignModel` rather than duplicated.

* `tests/lib/language/c/target.sml`: **83 checks**, including LP64, LLP64,
  both 32-bit alignment models, casts, promotions, lazy evaluation,
  unevaluated `sizeof`, arrays, unions, packing and explicit rejection.
* The unchanged frontend and new target suites passed on MLton, SML/NJ
  110.99.9 64/32-bit, SML/NJ 2026.2, Poly/ML and MLKit: **12 host suites**.
* Native probes compared **23** results on each of Linux x86-64/x86,
  Windows x86/x64, AArch64 and big-endian PowerPC: **138 comparisons**.
  Cross targets use the repository's Clang/sysroot/QEMU configuration;
  Windows probes use the installed MinGW toolchains and native execution.
* The final library selection passed **12/12** runner jobs, including the
  runner's canaries. The host/oracle/documentation selection passed 31/32;
  its sole failure was the host-inventory test's old hard-coded count after
  adding a suite. The count and an explicit target-suite coverage assertion
  were repaired; the focused repair selection then passed **6/6**. The
  final stack-interpreted target suite also passed **83/83**.
* `make docs JOBS=4` passed. Generated documentation is committed.

Reproduction:

```sh
make test-c-layout
bin/rune-test run 'lib/language/c/*' 'lib/ffi/model/*' -j 4
bin/rune-test run 'lib-hosts/*/language.c.target' \
  'lib-hosts/*/language.c.frontend' 'ffi/layout/*' \
  'ffi/frontend/fixture' 'runner/host-adapter' 'documentation/*' -j 6
```

Initial native-oracle compilation exposed a percent sign in a stringified
expression being treated as a printf directive. The oracle now prints the
expression through a `%s` argument. No failed initial run is counted as a
successful comparison. A first runner selection incorrectly combined
explicit filters with a tier intersection; its five canaries alone were
not acceptance evidence. The actual named selections are recorded above.

The [layout contract](../../../docs/ffi/layout.md) records supported
constructs and explicit adapter boundaries. Complete native marshalling,
selected SDL/Win32 layouts, compiled shims and repository/host acceptance
remain outstanding for M4.
