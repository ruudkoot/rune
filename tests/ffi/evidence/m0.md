# M0 baseline and acceptance — 2026-10-22

Implementation started in `.worktrees/runeffi`, branch `runeffi`, from a
freshly fetched `origin/master` at
`e875edca96ac5a15af83986b633c7f74a95aa144`.
The worktree started clean. The original checkout and its untracked
`.claude/worktrees/` were preserved. The roadmap's earlier documentary
baseline remains historical; this is the implementation baseline.

Host: x86-64 WSL2 Linux `6.18.33.2-microsoft-standard-WSL2`, Ubuntu 24.04.
C: GCC 13.3.0 (Ubuntu 13.3.0-6ubuntu2~24.04.1); independent frontend oracle:
Clang 18.1.3. Windows reference compilers: x86-64 and i686 MinGW GCC
13-win32, with native Windows execution through WSL interop. SDL release
3.4.18, SDK 10.0.22621.0, and libffi 3.4.6 have exact source manifests.
The SDK originals are externally installed and hashed, not redistributed.
Compiler-runtime headers are separately pinned to MSVC tools 14.40.33807
(`_MSC_VER=1940`); their 153 C headers also remain external.

## Results

* `make all JOBS=8`: passed, isolated worktree bootstrap.
* `make test-ffi-contracts JOBS=8`: 8/8 including runner canaries, 1.0 s
  wall. Elaborates public signatures and sharing constraints on both
  bytecode engines, checks the state-model trace, hashes 87 original SDL
  files (86 headers and licence), and verifies both inventories.
* `make test-ffi-libffi JOBS=8`: 6/6 including canaries, 1.0 s wall. Direct
  C and independent libffi scalar/aggregate/variadic/closure checks pass.
* `make test-ffi-windows JOBS=8`: 7/7 including canaries, 12.9 s wall.
  Native C and GUI oracles on both widths;
  confirms creation-time callbacks and nested sends on real Windows.
* Python 3.12.3 ctypes and pinned Poly/ML 5.9.2 comparison programs: passed
  scalar, struct result, owned string and retained-callback cases.
* Original SDK integrity: the SML SHA-256 verifier passed all 1,906 files
  in the pinned SDK manifest.
* Clang 18.1.3 with AddressSanitizer and UBSan: the 24 direct C checks pass.
  The probe uses C17 `_Alignof`; a nonstandard `offsetof` spelling was
  caught by Clang's strict warnings and corrected before acceptance.
* Public signatures elaborate with Rune and pinned MLton 20241230.
  A vanilla Poly/ML Basis lacks optional `Int8`/`Int64` structures; testing
  those signatures on Rune's own Basis compiled by hosts belongs to M2.
  This native-host limitation is not counted as a successful contract run.

Each native oracle prints target byte order, plain-char signedness, scalar
widths and the representative struct's size/alignment/offset. The SML
checker compares these with `ffi/targets/*.json`. Linux uses LP64; Windows
uses LLP64 on x86-64 and ILP32 on x86. In particular Windows `wchar_t` is
2 bytes on both widths; Linux `wchar_t` is 4. Native probes establish the
initial target facts independently of SML host arithmetic.

Test children have private output directories, deadlines and captured
streams. Full command identities and per-command times are printed by the
SML coordinator; repository runner events retain machine-readable results
under `tests/out/r/`. No committed artifact includes an acquisition path.

## Repository regression and repairs

`make doctor` passed outside the sandbox, including sanitizers, 32-bit C,
Windows tools and qemu. The restricted sandbox had falsely reported the
native sanitizer/32-bit probes unavailable; no package installation was
needed. `make envcheck ENVCHECK=--identity` recorded this WSL machine as an
unlisted fingerprint, not as a validated cloud performance baseline.

`make check JOBS=8` completed all **19,334** cases in 1,868.1 s:
19,328 passed, three documented skips, and three failures. The skips were
the two existing native-interrupt exclusions and an absent optional pinned
GMP dependency (system GMP remains available). Repairs and reruns:

* Register the independent ctypes subject in the required migration census;
  the inventory rerun passed.
* Rebuild the new FFI coordinator after its contract trace grew to include
  posting, timers and object restoration; both engines passed.
* Wait for the new raw prompt before readline fixture input, especially
  Ctrl-D after cancellation. This fixes a terminal-script synchronization
  race; it does not change editor behavior. Both readline cases passed.

The final FFI suites passed 8/8, 6/6 and 7/7; the terminal/inventory rerun
passed 9/9. These are focused repairs following the full run, not a claim
that the original failing full command returned success. The full run's
remaining cases passed, and no unresolved failure is hidden by a skip.
The two readline scenarios then passed **ten repeated runs under load**
(`--repeat 10 --under-load -j 2`), 8/8 cases including canaries each time.
Final `make test-ffi-contracts check-docs JOBS=8` passed 8/8 and 11/11;
generated documentation, library claims and ISA/doc consistency checks
were current. The source check covers all 26 requirement/test owners,
including explicit ownership of deferred backend extension points.
The release headers retain upstream whitespace, including trailing spaces
and final blank lines reported by Git's whitespace check. Their original
bytes take precedence; the handwritten changes pass `git diff --check`
with `ffi/sdl/upstream` excluded, and all upstream hashes match the release.

## Remaining gates

All 92 function selections explicitly retain unresolved policy annotations
for M2. M0 establishes contracts and test subjects, not usable bindings.
SDL is not installed system-wide; its verified source is cached for a
private build at M7. Interactive Linux/Windows GUI acceptance, original
header preprocessing, full generated type closures, other target ABIs,
SML-to-C calls, GC/reentry and all performance phases remain the gates of
M1–M10. No unavailable check counts as a pass.

Inventory correction during M1: the initial 54-function SDL list included
`SDL_RunApp`, which the roadmap explicitly defers. It is now recorded as
deferred, leaving 53 selected core SDL functions and 38 Win32 functions
(91 total). The earlier 54-function comparison results are historical;
removing that extra selection does not remove an agreed core API.
