# M3 generic dynamic-call acceptance — 2026-10-23

Implementation is isolated in `runeffi-runtime` while the primary worktree
validates M2. One trusted `foreign` primitive provides availability, native
target facts, dynamic libraries/symbols, zeroed storage, bounded views,
prepared scalar/pointer calls and deterministic release. No binding adds a
primitive. The existing GMP primitive inventory and role are unchanged.
`RuneForeign : RUNE_FOREIGN` is the Basis implementation bridge used by
ordinary libraries; its manual contract is in `docs/ffi/runtime.md`.

Native identities stay outside portable images and are never reused across
contexts. Dependencies prevent premature library/memory release. SML
liveness tombstones remain closed after save/restore. Live foreign resources
reject save, restore and fork before files/process state change. Native
errors are captured before arena cleanup or result conversion.

* Documentation validation: **11/11 PASS** after signature generation.

The Windows fixture initially used `SysWord.wordSize` for C pointer-sized
arguments; Rune's portable SML word width differs from the native C pointer
width. The bridge now reports pointer bytes, byte order and stdcall support,
and the fixture uses those ABI facts. The corrected fixture passes both
native Windows widths.

Host: Ubuntu 24.04 x86-64 WSL2, GCC 13.3, Clang 18.1.3, MinGW GCC 13-win32,
libffi 3.4.6. Windows libffi archives were built from the checked pinned
source independently for each width. Other cross targets preserve the
unavailable bridge until their libffi provisioning/ABI fixtures are added.

`make matrix-quick JOBS=8` passed **3,366/3,366** cases: **3,198 PASS**
and **168 documented unsupported-host-extension SKIP**, with no failures.
M3 acceptance is complete. Callback entry, aggregates, strings and variadic

not been relaxed by this milestone.
