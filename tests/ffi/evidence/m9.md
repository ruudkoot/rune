# M9 component evidence (in progress)

Date: 2026-10-23. M9 remains planned pending native/SDL integration,
shared application runs, packaging and cumulative repository acceptance.

The common library defines one sealed Win32 type module, stable public
WIN32 signatures and the thin SDL/mock driver boundary. Ten identity
checks passed. Queued messages now have explicit `discardMessage` cleanup
in addition to single-use dispatch, so lookahead copies can always be
released. The original prototype contract is updated with this additive
operation. Driver painting receives a client-clipped invalid rectangle
and requires persistent pixels outside partial repaints.

`Win32ModelFn` implements the shared class, window, message queue, filtering,
message timers, paint scopes and GDI ownership semantics. Each synchronous
activation has its own saved exception cell, with message-specific failure
values, suppression after failure, and cleanup before propagation. Nested
handled failures do not poison the outer activation. Creation failures,
creation-time identity, destruction inside Close, stale handles, selected
objects and callback-registration guards are covered.

`Win32Mock` instantiates that same model with an in-memory driver and a
controlled monotonic clock. It opens no native libraries. Its **22** unit
checks pass with `--gc-stress 7 --gc-verify` on register interpretation,
stack interpretation and both JIT tiers. The exact shared
`tests/ffi/win32/contract.sml` source passes **11/11** groups against the
mock. Its initial 9/11 result exposed one model error-code normalization
(timer staleness now consistently reports 6) and a fixture cleanup bug
(converting an already-deleted brush before the cleanup guard). Both were
repaired, and stale typed GDI views have explicit negative assertions.

The deterministic trace has a hand-reviewed **17-line** expected file,
including paint-region coordinates, fill colour, queued/synchronous
messages, timer ownership, visibility and destruction. The program's bytes
match that file exactly. Unsupported flags, synthetic lifecycle/pointer
messages, palette encodings and non-ASCII drawing are explicit, not silent
approximations. Invalidations coalesce and intersect the current client.

The model and mock signatures are documented and sealed; their generated
documentation is committed. `git diff --check` passes. Native execution,
Windows, host-library availability, full SDL contract and real clipped
pixel probes remain integration gates; the separate SDL driver evidence
records its own completed results. Native-host optional Word16/Int64
availability must be reported separately from Rune execution.
