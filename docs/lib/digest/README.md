# Digests

Hash functions read in pieces, bytes written as hexadecimal, and HMAC over
a hash. MurmurHash2 is here too: a fast hash that is no digest, which is
what a notebook's cell is named by.

## Digests

| Signature |  |
| --- | --- |
| [`DIGEST`](sig/DIGEST.md) | A hash function that reads its message in pieces: the context holds what it has read, and `finish` gives the digest, as raw bytes. |
| [`HEX`](sig/HEX.md) | Bytes written as hexadecimal digits, two to a byte, and read back. |
| [`HMAC`](sig/HMAC.md) | HMAC (RFC 2104): a message authenticated by a key, over a hash function, and the comparison of two of them in a time that does not depend on where they differ. |

## Data formats

| Signature |  |
| --- | --- |
| [`MURMUR2`](sig/MURMUR2.md) | MurmurHash2, 32 bits (Austin Appleby's, on x86): a fast hash that is no digest -- it resists no adversary -- which tools agree on by name, as JupyterLab's debugger names a notebook's cell by the hash of its code. |
