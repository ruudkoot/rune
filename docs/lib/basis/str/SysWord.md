## Synopsis

```sml
structure SysWord :> WORD
```

SysWord: the words of the operating system's interfaces, [`Posix`](../str/Posix.md)'s and
[`Windows`](../str/Windows.md)'s: their flags, modes and numbers. "The type SysWord.word is
guaranteed to be large enough to hold any unsigned integral value used by
the underlying system", which on a 64-bit system has 64 bits, so it is
[`Word64`](../str/Word64.md) behind, but a type of its own: not [`Word.word`](../sig/WORD.md#type-word), nor
[`Word64.word`](../sig/WORD.md#type-word), as the specification makes it the same as neither, and
other implementations keep it apart from each (MLton's is [`Word64`](../str/Word64.md), and
its [`word`](../sig/WORD.md#type-word) has 32 bits). A program converts with [`fromLarge`](../sig/WORD.md#val-fromlarge), [`toLarge`](../sig/WORD.md#val-tolarge),
[`fromInt`](../sig/WORD.md#val-fromint) and [`toInt`](../sig/WORD.md#val-toint).
