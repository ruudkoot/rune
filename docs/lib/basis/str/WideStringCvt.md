## Synopsis

```sml
structure WideStringCvt :> STRING_CVT where type char = WideChar.char where type string = WideString.string where type radix = StringCvt.radix where type realfmt = StringCvt.realfmt
```

WideStringCvt: the helpers of StringCvt over wide text, which build and
take apart strings of [`WideChar.char`](../sig/CHAR.md#type-char).

> **Deviation** `WideStringCvt/not-in-the-specification`. The specification
> has no such structure: its [`STRING_CVT`](../sig/STRING_CVT.md) is written over [`char`](../sig/STRING_CVT.md#type-char) and
> [`string`](../sig/STRING_CVT.md#type-string) (the deviation `STRING_CVT/generic`), so a scanner of wide
> characters has neither [`skipWS`](../sig/STRING_CVT.md#val-skipws) nor [`scanString`](../sig/STRING_CVT.md#val-scanstring) to build on. This one is
> [`StringCvt`](../str/StringCvt.md) over the wide characters, with the same [`radix`](../sig/STRING_CVT.md#type-radix), [`realfmt`](../sig/STRING_CVT.md#type-realfmt)
> and [`reader`](../sig/STRING_CVT.md#type-reader); white space is what [`WideChar.isSpace`](../sig/CHAR.md#val-isspace) accepts.
