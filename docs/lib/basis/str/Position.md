## Synopsis

```sml
structure Position :> INTEGER
```

Position: the positions in a file and in a stream of I/O, as `lseek` and
`ftruncate` take them and `fileSize` gives them: 64 bits, as a file
offset of the system has, and a type of its own. It is [`Int64`](../str/Int64.md) behind,
but not [`Int.int`](../sig/INTEGER.md#type-int) nor [`Int64.int`](../sig/INTEGER.md#type-int), as the specification makes it the
same as neither and other implementations keep it apart from [`Int`](../str/Int.md)
(MLton's and SML/NJ's are [`Int64`](../str/Int64.md), Poly/ML's [`LargeInt`](../str/IntInf.md)). A program
converts with [`fromInt`](../sig/INTEGER.md#val-fromint), [`toInt`](../sig/INTEGER.md#val-toint), [`fromLarge`](../sig/INTEGER.md#val-fromlarge) and [`toLarge`](../sig/INTEGER.md#val-tolarge).
