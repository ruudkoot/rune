# Property testing: the Basis Library's arbitraries

Arbitraries for the types of the Basis Library. There is one for each
structure, and functors make an arbitrary from a structure of `INTEGER`,
`WORD`, `REAL`, `CHAR`, `STRING` and the monomorphic sequences.
