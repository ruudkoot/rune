The classes of characters of the Haskell 98 Report's lexical syntax
(chapter 2, section 9.2), by code point.

Above ASCII the Report's classes are those of Unicode's general
category: `uniSmall` a lowercase letter, `uniLarge` an uppercase or
titlecase one, `uniDigit` a decimal digit, `uniSymbol` a symbol or a
punctuation mark, `uniWhite` a space, by the general category of
Rune's `lib/unicode` (the haskell98 roadmap's D21). A character of no
class, a letter of no case (Lo, Lm), a mark, a number not decimal, a
control or a format character, is refused outside a comment or a
literal; the lexer reads any character in a comment or a literal (the
reading R5).

A class of the lexical syntax.

| Constructor | Argument | Description |
| --- | --- | --- |
| <a name="con-small"></a>`Small` |  | `small`: `a` to `z`, `_` and a lowercase letter |
| <a name="con-large"></a>`Large` |  | `large`: `A` to `Z` and an uppercase or titlecase letter |
| <a name="con-digit"></a>`Digit` |  | `digit`: `0` to `9` and a decimal digit |
| <a name="con-symbol"></a>`Symbol` |  | `symbol`: `ascSymbol` and a symbol or punctuation that is not `special`, `_`, `:`, a quotation mark |
| <a name="con-white"></a>`White` |  | `whitechar`: space, tab, the line ends, vertical tab and a space above ASCII |
| <a name="con-special"></a>`Special` |  | `special`: one of `(),;[]` and the backquote and braces |
| <a name="con-colon"></a>`Colon` |  | `:`, which begins a constructor operator |
| <a name="con-quote"></a>`Quote` |  | the two quotation marks, `"` and `'` |
| <a name="con-unknown"></a>`Unknown` |  | no class: a control character, or a character above ASCII of none of the classes above |

### <a name="val-classify"></a>`classify`

```sml
val classify : int -> class
```

`classify c` is the class of the code point `c`; [`Unknown`](#con-unknown) for a
negative `c`.

### <a name="val-isident"></a>`isIdent`

```sml
val isIdent : int -> bool
```

`isIdent c` is whether `c` may continue an identifier: a small or a
large letter, a digit or `'`.

### <a name="val-issymbol"></a>`isSymbol`

val isSymbol : int -> bool

`isSymbol c` is whether `c` may continue an operator: a symbol or `:`.
