# C declaration frontend

This library preprocesses and parses C interface descriptions in Standard
ML. It has no dependency on a C compiler or an FFI runtime. Include loading
is an explicit resolver, and target predefinitions and expression widths
are caller-supplied. It does not infer SML names, ownership or errors.

[`CLex`](str/CLex.md) preserves original physical positions through line splicing and
comment replacement. [`CPreprocess`](str/CPreprocess.md) implements macro expansion and records
invocation origins, includes, compiler pragmas and final macro definitions.
[`CConst`](str/CConst.md) evaluates intmax/uintmax preprocessing expressions with lazy
logical/conditional operators and explicit signed-overflow diagnostics.
[`CEnumConst`](str/CEnumConst.md) folds retained enumerator expressions and implicit successors,
checking referenced declarations and preserving target-independent values.
[`CParse`](str/CParse.md) produces typedef-sensitive declaration trees, retaining aggregate
fields, bounds, bit widths, attributes, conventions, packing and inline
bodies. [`CFiles`](str/CFiles.md) supplies a portable file resolver using original bytes.

[`CInteger`](str/CInteger.md) implements target integer ranks, promotions, checked arithmetic
and two's-complement conversions. [`CType`](str/CType.md) normalizes equivalent scalar
spellings and parses abstract type names through the declaration parser.
[`CExpression`](str/CExpression.md) adds typed casts, `sizeof`, alignment and lazy operators;
unevaluated operands are typechecked without executing their arithmetic.
[`CLayout`](str/CLayout.md) computes target structs, unions, nested arrays, anonymous members,
flexible tails and pragma packing. Alias/tag lookup, constant values and
all scalar facts come from the caller. Bitfields and explicit alignment
attributes request a verified native adapter rather than guessing.

Inline bodies are balanced syntax, not compiled C statements. Target
layout and declaration-expression typing are explicit consumers of the
syntax tree; FFI projection remains separate. Unknown active directives or unsupported declaration syntax
produce source diagnostics. Original headers are never repaired in place.

[`CDeclarator`](str/CDeclarator.md) renders referenced C types without changing original header
bytes. It handles pointers, arrays and function declarators and requires
an original name for anonymous aggregate types.

[`CAnalysis`](str/CAnalysis.md) indexes original declarations and resolves selected typedefs, tags,
integer expressions and layouts using explicit target facts. Enum policy is
explicit: the supported Microsoft ABI uses signed int for full-int enums;
the supported System V ABI uses unsigned int for nonnegative full-int enums.
Unknown representation attributes and extended enum representations require
native adapters. Private unsupported declarations do not force evaluation.
