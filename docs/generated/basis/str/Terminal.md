## Synopsis

```sml
structure Terminal : TERMINAL
```

Terminal: the terminal of a program that edits what is typed at it, over
the runtime's term\_size, term\_resizes, term\_enter, term\_leave and
term\_read (runtime/sys/sys.h). It is Rune's own and not of the
specification.
