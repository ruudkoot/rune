# Types that are one type

[The Standard ML Basis Library](README.md)

Types with several names: a value of one is a value of the others, and a function on one takes
them all. They are found by elaborating the library and comparing the type names, so the table
says what is the case and not only what is meant. Much of it the specification requires
(`String.string` is `string`, `CharVector.vector` is `string`); the rest is a choice of this
library, and where the specification keeps a type abstract that is one of these here, a program
that relies on it is not portable: the type's own entry has a note that says so. A type that
abbreviates more than a name, such as a reader or a record, is not listed.
