A hash function that reads its message in pieces: the context holds
what it has read, and [`finish`](#val-finish) gives the digest, as raw bytes.

The context that has read nothing.

### <a name="val-update"></a>`update`

```sml
val update : context * string -> context
```

`update (c, s)` is `c` having read `s` after what it had read.

### <a name="val-finish"></a>`finish`

```sml
val finish : context -> string
```

`finish c` is the digest of what `c` has read.

**Law** `finish (update (update (empty, a), b)) = digest (a ^ b)` (for every `a : string`, `b : string`)

### <a name="val-digest"></a>`digest`

```sml
val digest : string -> string
```

`digest s` is the digest of `s`.

**Example** `Hex.fromBytes (Sha256.digest "abc") = "ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad"`
