# Free-group completion and rewriting validation

The final rewrite-lazy and rewrite-strict wrappers pass 54 of 56 primary cases.
Every Rune O0/O2 engine and five native hosts pass smoke and normal. Both
normal ML Kit attempts report allocation failure at the 4 GiB profile cap.
The executable was produced; coverage.tsv records these runtime memory failures.
All twenty semantic invocations pass 344 assertions: 6880 passing assertions,
none failed or unreached. Native runs use host-default options; their O0/O2
group labels repeat the native checks rather than selecting native optimizers.

Eight full-normal Rune count samples agree under the instruction/allocation
comparison conventions. Both final guarded processes exit zero without a guard
interruption. Six serial single fresh-process native smoke adapter samples pass,
recorded after the heavy correctness/count/repository jobs completed. They are
adapter diagnostics, not a ten-sample comparative performance report. Default
headline sample counts and measurement modes remain unchanged.

The original GHC program matches FAST/NORM/SLOW fixtures. An export-only observer
records the exact ten-rule completion theory and sixteen normal forms. A separate
signed-letter cancellation model agrees with the original on 128 generated
terms. The final SML checks preserve the numbered theory, all those full terms,
source substitution/arity behavior, lazy finite fields, short-circuiting, unused
singleton agenda costs and shared completion. Every measured query validates
its complete normalized tree and the driver checks its observation count.

Global completion remains shared across queries and repeated Benchmark.run calls;
zero queries leave both axioms and completion undemanded. Each call retains the
finite take/repeat query stream and its shared pair. Normal retains 250000
queries, large 1200000, and smoke reduces FAST's 20000 to one. Atomic SML strings,
tagged classification representation, explicit delays and additional full-term
consumption are recorded adaptations. Full final SML large repetitions remain
unrecorded.

The repository acceptance run exits zero with 1180 profiles and all compiler,
runedoc and runeopt cross-build comparisons. Its routine benchmark set is bounded;
the final new ports have separate explicit profile and semantic runs, including
the final lazy-cost fix. No compiler or runtime prerequisite was introduced.

Development scopes are retained separately. Provisional source-qualified names
were corrected because rewrite has no naming collision. Their measurements and
host-memory-guard interruptions do not supply final wrapper counts or samples.
The reserve guard stopped those processes when host available memory fell below
8 GiB, while their own RSS was below the 2 GiB guard; these are host-reserve
interruptions. A first semantic run used a private fixture path and failed its
theory-file checks; the final driver uses the supplied working-directory file.
An earlier eager-cost implementation omitted the singleton-cost demand rule;
the final 344-check target includes that regression in both variants. None of
these preliminary records are counted as final validation.

The literature review distinguishes the inspected opening sections of Knuth/
Bendix, Dershowitz's publisher abstract, the failed full-paper fetch, source-based
diagnostic hypotheses and measured results. Source identities, raw outputs,
options and resource records accompany the final evidence.
