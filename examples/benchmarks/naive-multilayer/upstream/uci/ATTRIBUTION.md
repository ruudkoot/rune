# Ionosphere data attribution

Sigillito, V., Wing, S., Hutton, L., and Baker, K. (1989).
Ionosphere [Dataset]. UCI Machine Learning Repository.
https://doi.org/10.24432/C5W01B

The [UCI dataset page](https://archive.ics.uci.edu/dataset/52/ionosphere)
identifies the creators and licenses this dataset under
[Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/).
The complete license and original data/names files are retained here.

All 351 source rows, 34 values per row, labels and order match the pinned
Sandmark dataset module. The portable text changes numeric minus spelling to
SML's tilde and represents the same good/bad classes. It introduces no
normalization, shuffle or train/test partition. These formatting adaptations
are recorded separately from the code's MIT notice.
