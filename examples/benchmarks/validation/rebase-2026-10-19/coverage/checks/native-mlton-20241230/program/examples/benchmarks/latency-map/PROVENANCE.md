# latency-map provenance

Source collection: Rune (no upstream)

Written for Rune's second-generation collector
([docs/plans/garbage-collector-v2.md](../../../docs/plans/garbage-collector-v2.md),
*The workloads*) on 2026-10-05, in the manner of James Fisher's "Pusher"
benchmark (2016) and Gabriel Scherer's gc-latency-experiment; no code of
either is used.

Inputs, validation and the evaluation set's sizes are recorded in [the suite README](../README.md#latency-map).
