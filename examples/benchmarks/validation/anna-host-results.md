# Anna host results

[Complete evidence](../results/m4-anna/README.md) records 45 passing
profile combinations out of 56, including every Rune engine/level/profile
combination. Host deadlines retain the unchanged resource policies.

The supplied SML/NJ32 reproduces the
[existing literal-loss defect](../../../docs/bugreport/smlnj/Word64-low-half/BUGREPORT.md):
the type-supply threshold becomes zero. A private single-threshold causal
probe restores the complete independent 837-byte smoke type report. The
public benchmark keeps the valid literal, and the host failure remains
visible. The diagnostic does not establish that every profile would pass
after changing only that constant.
