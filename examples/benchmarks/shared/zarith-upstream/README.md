# Arithmetic translation sources

Zarith 1.14 and Num 1.6 are the installed reference libraries. The retained opam
metadata pins their release archives with SHA256/SHA512 checksums. SHA256SUMS
identifies every retained source and notice. Their benchmark/library authorship
is recorded in the original files and package metadata; the short Sandmark
headers do not identify their individual adapter author.

Zarith's LICENSE contains GNU Library GPL version 2 and its linking exception.
Num's LICENSE contains LGPL version 2.1 and its linking exception. Preserve these
notices with translated portions; Sandmark's aggregate Unlicense does not replace
them. Num src/num.ml credits Valerie Menissier-Morain and copyright INRIA 1996.
No C library, GMP binding or runtime feature is needed by the SML ports.
